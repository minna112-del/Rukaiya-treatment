# রুকইয়াহ শিফা — MT Studio AI (সংশোধিত সংস্করণ, v5.1.0)

কুরআন ও সুন্নাহের আলোকে রুকইয়াহ বিষয়ক বাংলা ওয়েব অ্যাপ: তিলাওয়াত প্লেয়ার,
লক্ষণভিত্তিক সাধারণ নির্দেশনা, রুকইয়াহ পদ্ধতি, পকেট পেপার জেনারেটর,
দৈনিক সুরক্ষা রুটিন ও ডিজিটাল তাসবীহ।

## এই সংস্করণে যা ঠিক করা হয়েছে

- **চ্যাট: Gemini → ChatGPT (OpenAI)**
  - এখন `https://api.openai.com/v1/chat/completions` ব্যবহার করে, মডেল `gpt-4o-mini`।
  - **কোনো API key এই কোডে/রিপোতে নেই — ইচ্ছা করেই।** Key ব্রাউজারে
    হার্ডকোড করলে যে কেউ সেটা নিয়ে আপনার বিল/কোটা খরচ করতে পারবে।
  - চ্যাট নিজেকে আর “মহসিন বসের সহকারী / আরমান” বলে না, AI কিনা
    লুকায় না। পরিষ্কারভাবে বলা আছে: এটা AI সহকারী, চিকিৎসা বা
    ফতোয়ার বিকল্প নয়।
  - বটের উত্তর এখন escape করে দেখানো হয় (আগে raw `innerHTML` ছিল)।
- **লক্ষণ চেকার:** “সনাক্ত হয়েছে” → “সম্ভাব্য নির্দেশনা”। এটা
  ডায়াগনোসিস নয়, এবং তীব্র/হঠাৎ/দীর্ঘস্থায়ী শারীরিক লক্ষণে
  চিকিৎসকের পরামর্শ নেওয়ার কথা লেখা আছে।
- **কমিউনিটি ফিচার:** আগের `window.storage` API সাধারণ ব্রাউজারে
  নেই, তাই ভিউ/লাইক/রেটিং/মন্তব্য এখন `localStorage`-এ শুধু
  ব্যবহারকারীর নিজের ডিভাইসে থাকে। সাইটে সেটা পরিষ্কার লেখা আছে —
  আর “লাইভ দেখছে” সংখ্যা সরিয়ে দেওয়া হয়েছে।
- **অডিও লেবেল:** “শিফার দোয়া” আইটেমটি আসলে বাকারাহ ২৮৫-এর
  অডিও ছিল — এখন সঠিক নামে আছে। “ফালাক ও নাস” আইটেমে শুধু
  ফালাকের অডিও ছিল — এখন শুধু ফালাক লেখা আছে।
- **SEO/শেয়ার:** Open Graph ট্যাগ ও favicon যোগ করা হয়েছে।
- **অ্যাক্সেসিবিলিটি:** আইকন-শুধু বাটনে `aria-label`, আরবি
  লেখায় `lang="ar" dir="rtl"` যোগ করা হয়েছে।
- **PWA সততা:** অফলাইন ব্যানার ও ইনস্টল লেখা বদলে পরিষ্কার করা
  হয়েছে — অডিও/ভিডিওর জন্য ইন্টারনেট লাগবেই, কোনো service worker
  এখনো নেই।
- **পারফরম্যান্স:** `html2canvas` এখন পেজ লোডে নয়, শুধু পেপার
  সেভ চাপলে লোড হয়।
- **ফুটার:** দাবিত্যাগ (চিকিৎসা/ফতোয়ার বিকল্প নয়) ও যোগাযোগ
  হ্যান্ডেল (Instagram @mt_studio_ai, YouTube @mt_studio_ai46,
  Facebook Page: MT Studio) যোগ করা হয়েছে।
- **বাদ দেওয়া হয়েছে:** `chat-log.jpeg` — এটা পেজে ব্যবহার হতো
  না এবং এটা চ্যাট লগ নয়, একটি পোর্ট্রেট ছবি ছিল।

## AI চ্যাট চালানোর ২টি উপায়

### উপায় A — শুধু টেস্ট / নিজে ব্যবহার (দ্রুত)
1. সাইট খুলে চ্যাট প্যানেলের উপরের key ঘরে নিজের OpenAI API key দিন,
   “সেভ” চাপুন।
2. Key শুধু সেই ব্রাউজারের localStorage-এ থাকবে, কোডে বা সার্ভারে
   যাবে না (OpenAI-তে চ্যাট পাঠানো ছাড়া)।
3. অন্য ভিজিটরকে চ্যাট চালাতে হলে তাকেও নিজের key দিতে হবে।

### উপায় B — সবার জন্য চালানো (সঠিক উপায়)
`netlify/functions/chat.js` ফাইলে Netlify Function প্রক্সি দেওয়া
আছে — এটা একই সাইটের সাথে ডিপ্লয় হয়, আলাদা সার্ভার লাগে না।
Netlify-র Site settings → Environment variables-এ শুধু
`OPENAI_API_KEY` বসান (ঐচ্ছিক: `ALLOWED_ORIGIN` = আপনার সাইটের
ঠিকানা, `OPENAI_MODEL` = `gpt-4o-mini`)। `index.html`-এ
`CHAT_PROXY_URL` ইতিমধ্যে `/.netlify/functions/chat` বসানো আছে,
তাই আলাদা URL বসাতে হবে না। বিস্তারিত ধাপ NETLIFY-DEPLOY.md-এ আছে।

## GitHub Pages-এ দেওয়া
1. এই ফোল্ডারের `index.html` দিয়ে রিপোর পুরনো `index.html`
   বদলে দিন (এবং `chat-log.jpeg` মুছে দিন, যদি না সেটা
   ইচ্ছা করে রাখতে চান)।
2. GitHub-এ Settings → Pages → Deploy from branch → `main` / root
   নির্বাচন করুন।
3. সাইট খুলে চেক করুন: তিলাওয়াত বাজে কিনা, লক্ষণ নির্দেশনা ও
   ডিসক্লেইমার দেখা যায় কিনা, চ্যাটে key ছাড়া সতর্কবার্তা আসে কিনা।

  প্রুফরিড করানো — এটা এই সংশোধনে করা হয়নি।

  (যেমন Firebase/Supabase) লাগবে; এখন সেটা লোকাল-অনলি।
