# রুকইয়াহ শিফা

কুরআন ও সহিহ সুন্নাহর আলোকে রুকইয়াহ শরীয়্যাহ বিষয়ক সাধারণ তথ্য, তিলাওয়াত, দোয়া, দৈনিক সুরক্ষা রুটিন ও তাসবীহ — বাংলায়। লাইভ সাইট: https://allahborosa.netlify.app/

## ফাইল গঠন

- `index.html` — পুরো সাইট একটাই ফাইলে (তিলাওয়াত প্লেয়ার, লক্ষণ যাচাই, পদ্ধতি, দোয়া, রুটিন, তাসবীহ, কমিউনিটি, AI চ্যাট)।
- `netlify/functions/chat.js` — AI চ্যাটের সার্ভার-সাইড প্রক্সি (Netlify Function)। ক্লায়েন্টের পাঠানো system prompt বিশ্বাস করা হয় না; সার্ভার নিজের নিরাপদ prompt ব্যবহার করে।
- `logo.png` — সাইটের লোগো; `share.jpg` — শেয়ার ছবি (og:image); `chat-logo.png` — চ্যাটের আইকন।
- `netlify.toml` — Netlify সেটিংস (publish, functions, নিরাপত্তা হেডার)।
- `NETLIFY-DEPLOY.md` — ডিপ্লয় করার ধাপ (বাংলায়)।

## ডিপ্লয়

Netlify GitHub-এর সাথে যুক্ত — GitHub-এ পুশ করলেই অটো-ডিপ্লয় হয়। আলাদা build কমান্ড লাগে না (স্ট্যাটিক সাইট)।

## Environment Variable (Netlify → Site settings → Environment variables)

- `OPENAI_API_KEY` — **আবশ্যক**। চ্যাট চালাতে OpenAI API key। key কখনো কোডে বা GitHub-এ বসাবেন না।
- `ALLOWED_ORIGIN` — **আবশ্যক**। সাইটের ঠিকানা (যেমন `https://allahborosa.netlify.app`)। না বসালে চ্যাট সব origin-কে ফিরিয়ে দেয় — কোনো উত্তর আসবে না।
- `OPENAI_MODEL` — ঐচ্ছিক (ডিফল্ট `gpt-4o-mini`)।

## আপডেট করার নিয়ম

GitHub ওয়েবসাইট থেকে ফাইল আপলোড করুন (ফোনের ব্রাউজার দিয়েও করা যায়) — শুধু যে ফাইল বদলেছে সেটাই আপলোড করুন। সাধারণত শুধু `index.html` আপলোড করলেই হয়; Netlify নিজে ডিপ্লয় করে নেয়।

## পানির সেশন (রুকইয়াহ পানি)

ক্রম: বিসমিল্লাহ → ফাতিহা ১ বার → ইখলাস/ফালাক/নাস ৩ বার করে → আয়াতুল কুরসি ১ বার → বাকারাহ শেষ ২ আয়াত ১ বার → ফুঁ। মোট ১২ ধাপ / ১৩ বার বাজে; ১২তম ধাপের পর থেমে যায়, নিজে আবার শুরু হয় না।
